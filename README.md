# 💰 Budget App

A personal budget web app built from scratch with vanilla JavaScript — track income, expenses and savings, filter by month, and see your spending by category on a live chart.

🔗 **Live demo:** https://budget-app-weld-ten.vercel.app/

## ✨ Features

- Add income, expenses and savings (piggy bank 🐷)
- Live totals: income, expenses, savings and available balance
- Expense categories, with the category selector locked for non-expenses
- A date on every transaction, plus a monthly filter (with an "annual budget" view)
- Doughnut chart of expenses by category (Chart.js)
- Data saved in the browser (localStorage) — it survives a refresh
- Delete transactions
- Responsive, modern dark "neon" UI

## 🛠️ Built with

- HTML
- CSS (custom dark theme, gradients & animations)
- Vanilla JavaScript (no frameworks)
- Chart.js

## 🚀 Run locally

1. Clone or download this repository
2. Open `index.html` in your browser (or use the Live Server extension in VS Code)

## 📚 What I learned

Building this from zero, I practiced: DOM manipulation, events, arrays (`filter`/`forEach`/`push`), objects as dictionaries, `localStorage` + JSON, ternary operators, working with dates, integrating an external library (Chart.js), responsive design, and debugging from error messages.
